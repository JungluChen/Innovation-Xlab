# Project Fibula — Innovation XLab

**MSc Smart Industries and Digital Transformation · NUS · STAPLE · Innovation XLab**

Project Fibula is an animation-forward showcase site presenting how natural-language reconciliation requirements become stateful, auditable workflows through evidence-based design and industrial user research.

Live site: [fibula.ai](https://fibula.ai)

---

## What Is Project Fibula?

Industrial reconciliation — Accounts Payable 3-Way Matching, production BOM checks — breaks when fragmented invoices, purchase orders, receipt notes, and manufacturing records stop agreeing. Traditional extraction tools pull data but lose context when exceptions appear, forcing teams back into manual investigation.

Fibula turns that problem into a structured solution in four stages:

1. **Natural Language Prompting** — Operators describe matching rules, variance thresholds, and escalation paths in plain language.
2. **Agentic Workflow Synthesis** — Fibula converts that intent into reviewable, node-based workflow structures with full dependency mapping.
3. **Human-in-the-Loop Validation** — Teams inspect, simulate, and approve workflows before live execution.
4. **Stateful Live Deployment** — Deployed workflows preserve state across sessions, surface exceptions in real time, and maintain an audit-ready decision log.

---

## Research Foundation

The product design is grounded in evidence collected through rigorous user research:

- **Workflow Mapping** — Document types, matching keys, variance decisions, and exception paths were fully mapped before any interface changes were proposed.
- **Task-Based Testing** — More than 15 unguided think-aloud sessions across 11 participant cohorts captured hesitation, misclicks, confusion, and abandonment.
- **Evidence-Based Coding** — The 90% No-Help Rule kept testing consistent and translated repeated friction logs into concrete product fixes.

Observed failures were filed as operational risk signals across five journey stages (Start, Template, Configure, Test, Output), each driving a targeted product correction.

## The Site

The showcase is a single-page, scroll-driven 3D experience built for desktop, with a clean responsive fallback for mobile.

**Desktop experience:**

- File rain opening — industrial document cards (INV, PO, GRN, BOM, WO…) drifting in 3D space
- Morphing workflow graph — a central Three.js subject that transforms shape across every narrative phase
- GSAP ScrollTrigger choreography tying morph progress to scroll position
- Lenis smooth scroll

**Mobile experience:**

- Clean vertical content layout, all sections readable, no WebGL required

**Sections:** Problem → Workflow → Methodology → Risk Map → Findings → Impact → Team → CTA

## Development

```bash
npm install
npm run dev          # dev server on port 5180
npm run build        # static export to dist/
npm run preview      # preview the built output
npm run format       # Prettier formatting
```

Deploys automatically to GitHub Pages on push to `main` via GitHub Actions. The `dist/` build output is generated by CI — it is not committed to the repository.
